# 演示截图

三张，都存到这个目录下，文件名用下面这个：

| 文件名 | 截什么 | 怎么截 |
|---|---|---|
| `01-chat.png` | 页面打开的样子，能看到输入框和至少一轮对话 | 浏览器全窗口截图 |
| `02-tool-calls.png` | 问「有笔记的线性代数，30 块以内」之后，工具调用、书卡、回答要在一张图里 | 一屏放不下就缩一下页面（Ctrl+-），别只截一半 |
| `03-offline.png` | 「AI 服务没启动」那个红框 | 把 uvicorn 停掉，随便发一句，截图，再把服务起回来 |

第 2 张最重要。只放回答的话，看的人分不清「agent 自己决定查了库」和
「硬编码了一段文字」，页面上「Agent 的工具调用」那一栏才是它真在决策的证据。
